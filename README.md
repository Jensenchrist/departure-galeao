# DEPARTURE · Galeão

Jogo de controle de aeroporto no Galeão (GIG), Rio de Janeiro.

- Escolha a posição de desembarque de cada voo que chega
- Acompanhe os serviços em solo e libere a partida
- O vento escolhe a cabeceira em uso (10 ou 28)
- O dia passa: tarde e noite
- Mapa de voos com todo o globo

## Jogar no iPhone

1. Em **Settings → Pages**, publique a branch `main`, pasta `/ (root)`.
2. Abra o endereço no Safari → **Compartilhar → Adicionar à Tela de Início**.
